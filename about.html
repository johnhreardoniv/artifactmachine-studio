About the machine

Tiny useful things from the machine.

What this is

A small catalogue of single-purpose website audit tools. Each one does one job, takes a URL, and returns structured JSON. They are built to be called by other software as much as by people.

What it is not

Not a platform, not a dashboard, not a monitoring service. Nothing here needs an account with us, stores your data, or emails you. If a tool would need to run continuously on your behalf to be useful, it does not get built — a service that quietly stops working is worse than no service, and we would rather ship the thing that cannot fail silently.

Pricing

Every tool is pay-per-result, between $0.50 and $3.00 per record, billed through Apify. There is no subscription and nothing to cancel. A run that returns no results costs nothing.

Honest status

These are new. 11 tools are published and health-checked every day, but the catalogue has no meaningful external usage yet, and this page will not pretend otherwise. There are no testimonials here because there are no customers yet to quote. When that changes, this paragraph changes.

What the tools will not tell you

Automated checks find machine-checkable problems. They do not certify accessibility, they do not determine legal compliance, and they do not replace a person looking at the page. Each tool page says where its own limits are, because a tool sold past its limits is worse than no tool.
