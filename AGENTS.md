# Artifact Machine site

- Current public site: `https://artifactmachine.studio/`, served by GitHub Pages from `main` with `CNAME` and `.nojekyll`. Check the live response and `origin/main` before deploying; an older `feat/beacon` branch contains a different Worker-based site and is not the current production source.
- The Meshtastic journey lives in `meshtastic/`: landing page at `/meshtastic/`, Basics at `/meshtastic/basics.html`, Field Operations at `/meshtastic/field.html`, Mesh Design at `/meshtastic/design.html`, and the three-device setup companion at `/meshtastic/setup.html`. Keep relative links and media assets working both at `/meshtastic/` and `/meshtastic/index.html`. The landing script redirects old `/#lesson-N` bookmarks to Basics.
- The courses are static HTML, CSS, JS, and local images. Check scripts with `node --check meshtastic/landing.js`, `node --check meshtastic/app.js`, and `node --check meshtastic/journey.js`. Test the landing page, each course, setup page, lesson links, quiz progress, navigation, and narrow layout in a browser before publishing. `meshtastic/COURSE_DESIGN.md` records the course design findings.
- The topic-to-course authoring skill is versioned at `skills/lesson-creator/SKILL.md`; the website implementation skill is at `skills/build-explainer-course/SKILL.md`. Both are installed locally under `~/.codex/skills/`.
- Publish this GitHub Pages site by committing changes on current `main` and pushing to `origin main`, then verify the live URL. The Worker branch's `wrangler deploy` workflow does not publish the current site.
- Keep `.dev.vars`, `.wrangler/`, and `dist/` out of Git and the published site. Do not read or stage credentials.
