The rhythm

How this keeps running.

Every morning

Each published tool is run against a known target. Anything that stops answering correctly is disabled automatically, so a broken tool cannot quietly keep charging.

Continuously

A watcher tracks tools in this category being retired, acquired or abandoned. Ground somebody else has vacated is the only ground worth building on.

Next

Undecided, honestly. Twenty-seven tools are built and waiting, and which one earns a slot depends on a question not yet answered. When it is, it appears on the lifecycle page first.

Where this actually stands.

Eleven tools are published and eleven work — checked automatically every morning. Twenty-seven more are built and unreleased, because publishing a tool is a promise to keep it running, and that promise gets harder to keep with every one added.

None of them has a meaningful number of users yet. If you came looking for social proof, there isn't any — and a studio willing to invent it is a studio willing to invent a passing grade in an audit report.

What gets retired, and why, is recorded on the lifecycle page. It stays recorded after it is gone.
