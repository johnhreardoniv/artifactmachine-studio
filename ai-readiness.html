What's behind the number

    What this does not tell you

    It reads one page, the homepage, and it checks machine readability only. It says nothing about performance, accessibility, security headers, broken links, or whether the writing is any good. A high score here is not a healthy site; it means a machine can parse this page.

    It also cannot tell you whether an AI assistant actually mentions you today. That is a different measurement. It needs repeated sampling of the models themselves, and several companies sell it. This is the cheaper question underneath it: if a model does come looking, is there anything here it can use?

    Where the numbers come from

    The same scanner and the same scoring produced the 57-site study, so a number here means what it means there. Search readiness is meta completeness, heading structure and structured data. Answer-engine readiness is whether the page states answers a machine can lift: question headings, marked-up Q&A, self-contained claims, plus whether the page needs JavaScript to say anything at all.

    The gap is the finding, not the score. Almost every site scores badly on answer-engine readiness: across 57 companies the median was 24 and nobody cleared 69. On its own that is weather. It only becomes a problem worth money when a site has clearly paid for search and is getting none of that value back.

    Why does it sometimes refuse to give a score?

    Because it could not read the page. Bot protection, a challenge screen, or a server error all produce a document that is not the site. Scoring that would describe an empty page and blame the owner for it, so we return nothing and say why.

    Do you store the addresses people check?

    No. The scan runs and the result goes back to your browser. Nothing is written down, and there is no account to create.

    Can I check more than one page, or a whole site?

    Not here. This reads one page so it can stay free and instant. A full crawl is a different job. Get in touch if that is what you need.
